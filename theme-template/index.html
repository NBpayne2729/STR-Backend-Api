Endpoints

These API routes power the booking plugin and are reflected in the JSON template.

  • GET /booked-dates for availability
  • POST /sync-calendar to ingest iCal data
  • POST /create-booking to store reservations
  • POST /create-stripe-session to begin payment
  • POST /send-confirmation to notify guests
